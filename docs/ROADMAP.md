# 월드 다이스 투어 — 로드맵

> 기준일 2026-09-22. 규칙의 원문은 [SPEC.md](SPEC.md), API 계약은 [API.md](API.md).
> 브랜치 흐름: `feature/*` 또는 `fix/*` → 코드리뷰 → `dev`(--no-ff) → 검증된 시점에 태그 → 플레이 사본 교체.
> 모든 금융 기능은 **방 옵션 기본 OFF**. 켜지 않은 방은 지금과 똑같이 돌아간다.

## 원칙

- **순수 운**: 아이템·캐릭터·스킬·내부정보 없음. 주사위·카드·시세는 서버의 난수로만 정해지고, 플레이어는 "살까 / 지을까 / 걸까 / 사둘까"만 고른다.
- **경제 배움 게임**: 새 상품마다 한 줄 해설(뉴스의 "왜"), 첫 거래 안내 카드, 종료 시 상품별 손익과 현실 직시 코멘트.
- **과적 방지**: 기능은 방 옵션으로 단계별 활성화, 계산은 서버가 자동, 기능을 붙일 때마다 자동 대전·실플레이로 판 길이와 재미를 다시 확인.
- **모바일 1순위**: 오너가 폰으로 플레이한다. 모든 화면은 360px 세로 화면에서 먼저 검증한다.
- **이모지 없는 UI**: 화면 문구·배지·토스트·로그에 이모지를 쓰지 않는다(프로토타입 느낌 방지). 아이콘은 인라인 SVG나 CSS 도형으로.
- **돈의 단일 통로**: 모든 돈 이동은 `Treasury` 한 곳에서만 적용되고, 매 커맨드마다 `총현금 + 잭팟 = 초기총액 + 은행순유입`이 검증된다.

## 후보 (실플레이 검증 뒤 결정)

- 인플레이션(가격·통행료·월급 점진 상승), 세금(매도차익·보유세), 보험(티켓 악재 방어). 환율은 비추천.
- 카지노 홀짝 하우스 엣지(현재 기대값 1.00 → ×1.9 제안) — 오너 결정 대기.
- 상장폐지 긴장감(25라운드 지평에서는 주식이 거의 상폐되지 않음) — 코인 단계에서 다시 검토.
